Jordan: Folder ready, placeholder page written. How does it get from my laptop to the internet?
Alex: With three verbs: stage, snapshot, ship. You create a public repository on GitHub, and you move your files with Git. Git add stages your files, git commit takes a snapshot with a message like Milestone One, placeholder page, and git push ships that snapshot to GitHub. Then the magic step: in the repository, open Settings, then Pages, choose Deploy from a branch, pick the main branch and the root folder, and save. After a minute or two, your site has a live address, something like your username dot github dot io slash your repo name.
Jordan: That sounds almost too easy. What goes wrong?
Alex: The classic: uploading the folder instead of its contents. If index dot html sits inside a subfolder of the repository instead of at the top level, GitHub Pages cannot find it, and your live address shows a four hundred four. The fix is to upload the contents of your project folder so index dot html lands at the repository's top. The second classic is impatience: Pages needs a minute or two, so wait before panicking.
