Chapters 2–5One site, four milestones

The course project

You build one website across Chapters 2–5, one milestone per chapter. Each milestone uses the chapter you just finished, so by the end of Chapter 5 the site is valid, semantic, styled and accessible, with a data table and a form, and it is live on the web. Then you submit your repository and live URL.

Pick from ten themes (a food truck, a pet shelter, a game guide…) or propose your own. The project page has checklists, rubrics, starter files and an automatic checker for your HTML.
